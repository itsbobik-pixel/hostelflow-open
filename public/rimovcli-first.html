The first RiMovCli file

The portal only takes a day that follows on from the last one it has. If your property already sent days before HostelFlow, the first file has to start from those numbers. You do this once — it takes about 2 minutes.

  1. Open the portal

    Sign in to the RiMovCli portal of the Region Liguria. On the home page you see the box Ultimo giorno caricato with the date and a table of countries.

  2. Copy the whole box

    Select everything in the box, from Ultimo giorno caricato down to the TOTALE row, and copy it (Ctrl + C, on a Mac ⌘ + C).

    Take the date line too — HostelFlow reads the date from it.

  3. Paste it in HostelFlow

    In HostelFlow open Settings → Reports → RiMovCli. At the bottom, open Manual edit for the first entry.

    Paste it into the big box. HostelFlow keeps only what it needs: the date and the Presenti number of each country.

    Can't copy it (on a phone, for example)? Press Fill in from screenshots and choose screenshots of the box — up to 4, if the table scrolls. Check what was filled in.

  4. Create the file

    Press Create XML file, then Download XML. The file covers the days from the one after the portal's last day up to yesterday.

  5. Upload it to the portal

    Upload the file on the portal as you upload the daily files. From then on just download the next days in Settings → Reports → RiMovCli — each file follows on from the one before.
